# custom-crm

A custom CRM, built by a team of 5 to learn how CRMs really work and to make a build-vs-buy case, with HubSpot as the benchmark. We start with the **Sales team**.

- **[PLAN.md](PLAN.md)**: the build plan: stack, how we work, assumptions to confirm, and the ordered task list.
- **[Issues](https://github.com/Hardeep-vt/custom-crm/issues)**: one issue per task. Pick the lowest-numbered open one whose dependencies are done.
- **[docs/meetings/](docs/meetings/)**: meeting summaries. Give these to an LLM along with PLAN.md as context.

Stack: FastAPI + PostgreSQL + React (Vite, TypeScript).
